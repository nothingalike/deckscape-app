# Triage labels

Use these default role strings in the local tracker's `Status:` field when triaging tickets.

| Skill role | Tracker value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the ticket. |
| `needs-info` | `needs-info` | More information is needed. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for agent implementation. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Maintainer has decided to leave the request unimplemented. |
